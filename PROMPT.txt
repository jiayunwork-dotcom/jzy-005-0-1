做一个可独立部署的一维三次样条插值服务，让上游把一组已知的采样节点（严格递增的横坐标与对应纵坐标）交给它，服务在这些节点上构建自然三次样条，之后对任意查询横坐标返回插值结果，并能返回样条在该点的一阶导数。这是一个纯服务端的数值计算组件，不是绘图工具、不涉及前端页面与账户体系。

核心插值：给定 n 个节点，构建分段三次多项式，要求整条曲线在每个内部节点处函数值、一阶导数、二阶导数都连续；自然边界条件为两端二阶导数为零。求解各段系数需要解一个三对角线性方程组，服务要保证解法在节点数较大时仍然数值稳定、不出现明显误差累积。构建完成后，对落在节点范围内的查询点返回插值值与一阶导数；对超出节点范围的查询点，按调用方指定的策略处理：要么明确拒绝并返回可区分的错误，要么按端点线性外推，策略可配置。

输入校验与边界：横坐标必须严格递增，出现重复或逆序要返回错误；节点数少于构建三次样条所需的最小数量、横纵坐标长度不一致、坐标含非有限值（NaN、无穷）等情况都要在构建前明确拒绝并给出可区分的错误类型，而不是崩溃或返回脏数据。

必须守住的行为：查询点恰好落在某个节点上时，返回值必须等于该节点的已知纵坐标（过节点）。把全体节点纵坐标整体加上一个常数，所有查询点的插值结果应相应地加上同一常数；把全体纵坐标乘以一个常数，插值结果应相应地按同一比例缩放（线性性）。当输入节点恰好落在一条直线上时，插值结果在任意查询点都应落在这条直线上，一阶导数处处等于该直线斜率。相邻两次插值请求携带不同的节点集合时，结果必须互不干扰。请预置一个可直接调用的算例：一组已知节点，调用后在若干查询点返回插值值与导数。

接口与运维：对外提供一个接收节点集合与查询点集合、返回各查询点插值值及一阶导数的计算接口，以及查询服务能力与当前配置的接口。所有非法输入以结构化错误响应返回并区分类型。服务需暴露基本运行状态供监控采集，且在并发处理多个插值请求时结果互不干扰。

技术上用 Python 实现，基于 FastAPI 提供 HTTP 服务，提供 Docker 一键构建并启动该服务。附带覆盖上述关键行为的自动化测试：过节点值精确、整体平移与缩放的线性性、共线节点插值落在直线上且导数等于斜率、横坐标逆序与重复被拒、节点数不足与长度不一致与非有限值被拒、越界查询按配置策略处理、以及并发多请求互不串扰。
